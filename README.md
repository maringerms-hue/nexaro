# NEXARO – Performance Eyewear

Konzept-Website für eine fiktive Performance-Sportbrillen-Marke: Scroll-gesteuerte Produktinszenierung, Kollektion und ein kurzer Weg vom Modell bis zum Warenkorb.

**Live-Prototyp:** https://maringerms-hue.github.io/nexaro/  
**Fallstudie:** https://maria-springer.webflow.io/projekte/brillen-konzept

## Umsetzung

- HTML, CSS und Vanilla JavaScript – ohne Framework, ohne Build-Schritt
- Scroll-Szenen mit Videosequenzen (MP4 + WebM) und Standbildern als Fallback
- Bilder als WebP, Videos komprimiert
- Tastaturbedienbar, Skip-Link, „Bewegung reduzieren“ wird respektiert

## Lokal starten

```bash
npx serve .
```

## Hinweis

Konzeptprojekt mit fiktiver Marke. Produktbilder und Videos sind mit KI erstellt (ChatGPT, Kling).
